Open a browser (I used Chrome)-> Open Developer Tools (F12)
Tick preserve log box to see the reirections and all the log in general

Network Tab:
Check the HTTP requests/responses in real-time
See status codes, headers, timing (click on any request on the list)

-----Normal Pages-----

http://localhost:8080/ -> 200 (/home.htm with css, image and font)
http://localhost:8080/index/ -> 200 (index/index.html)
http://localhost:8080/index/no-extension -> 200 (browser downloads file /index/no-extension)

-----Autoindex-----

http://localhost:8080/autoindex -> 200 (autoindex listing)
http://localhost:8080/autoindex/off/ -> 403 (forbidden)

-----Errors-----

http://localhost:8080/invalid-path -> 404 (errors/404.html)
http://localhost:8080/index/invalid-path -> 404 (Built-in 404 page)
http://localhost:8080/autoindex/off/invalid -> 404 (errors/404.html)

-----Redirection-----

http://localhost:8080/redirect/perm -> 301 then 200 (next request: 200 as browser saves in cache -> think of clearing cache before test!)
http://localhost:8080/redirect/tmp -> 302 then 200
