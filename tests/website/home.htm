Testing Instructions

  • Open browser Developer Tools (F12) → Network tab → Tick "Preserve log"
  • Follow tests in the table below:
    • GET and POST requests: click the links
    • PUT and HEAD requests: run the command in console

Tests list

HTTP Method Link / Command Expected Result Notes
📁 Static Content - OK
GET http://localhost:8080/ 200 Home page with CSS, image and font
GET http://localhost:8080/index/ 200 Custom index index/index.html
GET http://localhost:8080/index/no-extension 200 Browser downloads file
PUT curl -X PUT http://localhost:8080/put-demo.txt -d "new content" 200 Demo file for PUT testing
PUT curl -X PUT http://localhost:8080/your-new-file.txt -d "your content" 201 Create any new file
HEAD curl -I http://localhost:8080/put-demo.txt 200 HEAD request (headers only, no body)
